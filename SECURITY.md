# Security policy

Do not report credentials, unpublished biological data, or exploitable details
in a public issue. Use GitHub's private vulnerability-reporting channel for this
repository:

https://github.com/optima-manent/BioDataome/security/advisories/new

Include the affected version, component, reproduction conditions, impact, and
any known mitigation. Provider credentials should be revoked immediately if
they may have been exposed.

Only repository code is covered by this policy. Security or availability
incidents in NCBI GEO, ontology services, model providers, or other upstream
services should also be reported through the provider's own channel.
